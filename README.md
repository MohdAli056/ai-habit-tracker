# Cadence AI Habit Tracker

Cadence is an independently built MERN habit-tracking application. It will help people create habits, record daily progress, understand patterns, and use optional AI guidance to build sustainable routines.

## Planned stack

- Frontend: React 19, Vite, Tailwind CSS v4, React Router, Axios, Recharts, Lucide, React Markdown, and canvas-confetti.
- Backend: Node.js, Express, MongoDB Atlas with Mongoose, JWT, bcryptjs, CORS, dotenv, date-fns, and Google Gemini.

## Project layout

- `frontend/` contains the browser application.
- `backend/` contains the REST API and database integration.

## Planned AI capabilities

Future phases will add a weekly report, habit suggestions, streak-recovery coaching, habit-data chat, and morning motivation through Google Gemini. These capabilities are not implemented in Phase 0.

Local development instructions will be documented as implementation progresses.
